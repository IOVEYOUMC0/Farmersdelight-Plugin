CraftEngine behavior help for NovaFarmersDelight

1. tall_crop minimal example

behaviors:
  - type: farmersdelight:tall_crop
    grow-speed: 0.25
    light-requirement: 9
    is-bone-meal-target: true
    requires-water: true
    random-bone-meal-growth: true
    bottom-block-tags:
      - minecraft:dirt
    bottom-blocks:
      - minecraft:farmland

Notes:
- `age-property` is only needed when your crop does not use the default `age` field.
- `half-property` defaults to `half`.
- `tall_crop` now follows CE `double_high_block` naming more closely:
  - lower half: `lower`
  - upper half: `upper`
- These options are recommended to be configured explicitly for readability:
  - `grow-speed`
  - `light-requirement`
  - `is-bone-meal-target`
- If `is-bone-meal-target` is omitted, it defaults to `false`.
- The following options can usually be omitted because they are inferred or have stable defaults:
  - `half-lower-value: lower`
  - `half-upper-value: upper`
  - `max-age-lower: 4`
  - `max-age-upper: 3`
  - `reset-on-harvest: true`

2. Soil rules supported by tall_crop

`bottom-block-tags`
- Matches CE/custom block tags and vanilla block tags.
- Example:
  bottom-block-tags:
    - minecraft:dirt
    - minecraft:farmland

`bottom-blocks`
- Supports vanilla block ids:
  - minecraft:farmland
  - minecraft:stone

- Supports exact vanilla block states:
  - minecraft:dirt_path
  - minecraft:dirt[snowy=false]
  - minecraft:farmland[moisture=7]

- Supports CE custom block ids:
  - your_namespace:custom_soil

- Supports exact CE custom block states:
  - your_namespace:custom_soil[level=2]

Matching priority:
- If `bottom-blocks` / `bottom-block-tags` are configured, tall_crop uses them first.
- If nothing is configured, the plugin falls back to its built-in default soil rules.

3. Recommendation

Use `bottom-block-tags` for broad categories and `bottom-blocks` for exceptions.

Recommended rice example:

behaviors:
  - type: farmersdelight:tall_crop
    grow-speed: 0.25
    light-requirement: 9
    is-bone-meal-target: true
    requires-water: true
    random-bone-meal-growth: true
    bottom-block-tags:
      - minecraft:dirt
    bottom-blocks:
      - minecraft:farmland

4. Recipe syntax style

To keep recipe files close to CE style:

- Use `#namespace:tag` when the entry is a tag.
- Use `namespace:item` when the entry is a single item.

Examples:

- Cutting board tool tag:
  - `#farmersdelight:knives`
  - `#minecraft:axes`

- Cutting board single tool item:
  - `minecraft:shears`

- Cooking pot ingredient tag:
  - `#minecraft:planks`

- Cooking pot ingredient alternatives:
  - `minecraft:cod|minecraft:salmon|#your_namespace:raw_fish`
