# 切菜板

**切菜板（Cutting Board）** 让你用工具加工单个物品 —— 把肉和鱼切成小份、剥原木、把作物拆成部件等等。
它是你从前期起就会频繁使用的廉价工作站。

## 合成切菜板

有序合成（工作台）：

```
[ 木棍 ] [ 木板 ] [ 木板 ]
[ 木棍 ] [ 木板 ] [ 木板 ]
```

- `S` = `minecraft:stick`
- `P` = 任意木板（`#minecraft:planks`）

产物：`farmersdelight:cutting_board` ×1。

## 使用方法

1. 像放普通方块一样放置切菜板。
2. **手持物品右键** 把该物品放到板上（从手中放上一个）。
3. **再手持合适的工具右键** 进行加工，产物会从板上弹出为掉落物。
4. **空手右键** 把物品取回。

若板上物品有切割配方、但你手里的工具不对，会在动作栏提示工具错误；若该物品根本没有切割配方，则提示没有配方。

### 哪些工具可用

切菜板接受：

- **各类小刀** —— `#farmersdelight:tools/knives` 标签（燧石刀、铁刀、金刀、钻石刀、下界合金刀）。小刀是切菜板的主力工具，
  能解锁最多配方。
- **斧** —— `#minecraft:axes`
- **镐** —— `#minecraft:pickaxes`
- **锹** —— `#minecraft:shovels`
- **剪刀** —— `minecraft:shears`

每个配方各自指定所需工具。例如切生肉和鱼需要小刀，部分配方则要用剪刀或斧。可用 `/fd recipe` 打开 **切菜板配方** 列表，
查看每个配方需要的工具。

### 产物与概率

一个配方可以有多个产物，且每个产物都可带 **掉落概率**。有些副产物（如稻谷额外产出的稻草）只有一定几率出现。

**时运有加成：** 若切割工具带有时运附魔，每个产出单位都会获得额外掉落几率（每级时运 +10%）。时运不会让产物超过其正常上限数量 ——
只是让带概率的额外产出更稳定。

### 工具耐久

每次加工会消耗工具 **1 点耐久**（生存模式下）。若这一刀会让工具损坏，则工具用尽并伴随常规破碎音效。无法破坏／不可损耗的工具不会被消耗。

## 堆叠模式

视服务器配置而定，切菜板可能允许 **堆叠**：手持相同物品右键会把它叠加到板上已有的堆里（不超过板的堆叠上限），
而非只能放一个。关闭堆叠时，板一次只放一个物品。每次切割处理堆中的一个物品。

## 把工具摆到板上（雕刻式摆放）

若对空板 **潜行 + 右键** 且主手拿着工具，工具本身会被摆到板上（一种装饰性的「雕刻」摆放），而不是用来切割。空手右键即可取回。

## 比较器输出

切菜板会按其相对堆叠上限的填充度发出 **红石比较器信号**。单个不可堆叠物品（如工具）读作满强度；64 堆叠物品的一个单位读作最小值。

## 小贴士

- 快捷栏常备一把小刀 —— 它是切菜板的首选工具，制作也便宜（见配方列表中的小刀部分）。
- 在板上切生肉／鱼通常比整块产出更多小份，能拉长食物供给。
- 给小刀附上时运，可从带概率产出的配方中榨出更多副产物。
- 拿不准某物品能切出什么、或该用哪种工具时，用 `/fd recipe` →「切菜板配方」查阅。
