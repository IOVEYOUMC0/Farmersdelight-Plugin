# 炖锅

**炖锅（Cooking Pot）** 是农夫乐事的核心。它把食材架在热源上慢炖，做出各种炖菜、汤品和丰盛料理。
这些料理回复的饥饿值远高于生食，其中不少还会在进食后附带一段有益效果。

## 合成炖锅

有序合成（工作台）：

```
[ 红砖 ] [ 木铲     ] [ 红砖 ]
[ 铁锭 ] [ 水桶     ] [ 铁锭 ]
[ 铁锭 ] [ 铁锭     ] [ 铁锭 ]
```

- `B` = `minecraft:brick`（红砖物品，不是红砖块）
- `S` = `minecraft:wooden_shovel`
- `W` = `minecraft:water_bucket`
- `I` = `minecraft:iron_ingot`

产物：`farmersdelight:cooking_pot` ×1。合成后 **空桶会返还** —— 水桶在合成炖锅时会在工作台里留下一个
`minecraft:bucket`。

## 放置与加热

1. 把炖锅放在 **热源** 上方。只有炖锅正下方存在热源时，它才会开始烹饪。
2. 右键炖锅打开烹饪界面。

**哪些方块算作热源**（指炖锅正下方那一格）：

- 点燃状态的 **炉灶** `farmersdelight:stove`（fire 为点燃）
- 点燃状态的 **营火 / 灵魂营火**（必须已点燃）
- `minecraft:magma_block`（岩浆块）
- `minecraft:lava`（岩浆）或 **岩浆炼药锅**
- `minecraft:fire` / `minecraft:soul_fire`
- 服主在 `farmersdelight:heat_sources` 标签或 `config.yml` 热源列表中额外添加的任何方块

**漏斗** 会作为「导热体」：若炖锅正下方是漏斗，则漏斗再下面一格的热源仍能给炖锅加热。这样你可以一边用漏斗喂料，
一边从更下方加热。

## 烹饪界面

打开炖锅后是一组格子：

- **食材格（6 个）** —— 把配方所需的食材放进来。
- **成品格** —— 烹饪完成后的料理出现在这里。
- **容器格** —— 放入配方需要的容器（通常是 `minecraft:bowl` 碗）。
- **产出格** —— 当料理需要容器时，装好容器的成品会被推到这里，供你取出。

### 烹饪流程

1. 把符合某个配方的食材放进食材格。
2. 保持炖锅下方热源持续燃烧。
3. 经过该配方的烹饪时间后，食材被消耗，料理出现在成品格。

部分料理需要 **盛在容器里**。例如大多数炖菜和汤都用碗盛。若料理需要碗：

- 把碗放进容器格，成品会连同碗一起送到产出格；或者
- 直接 **手持碗右键炖锅** —— 消耗一个碗，料理直接进入你的背包。

不需要容器的料理（例如整块的食物方块）可直接从成品格取走。

默认烹饪时间为 200 tick（10 秒），具体时间由各配方自行设定。

## 配方查看器与「仅可制作」筛选

不必死记配方。用以下命令打开配方查看器：

```
/fd recipe
```

它会列出服务器上所有炖锅配方（以及切菜板配方）。点击某个配方即可查看其食材、容器与产物。

查看器里有一个 **筛选开关**：

- **显示全部配方** —— 列出所有配方。
- **仅显示可制作配方** —— 只列出你当前真正能做出的配方，依据是你背包里的食材（外加你打开查看器时那口炖锅里已有的东西）。

> **说明（行为正在收尾）：** 「仅可制作」筛选的设计目标是精确显示你当前已备齐食材的配方。该行为正由一项进行中的
> 修复统一处理；若你看到的结果暂时与背包不符，原因即在此。

从炖锅打开查看器时，选中某个配方还能把所需食材从背包自动放入锅中。

## 取出料理

- **需容器的料理（炖菜／汤）：** 手持碗右键，或把碗放进容器格后从产出格收取。
- **其他料理：** 直接从成品格取走。

部分配方用到的容器（如碗或玻璃瓶）会返还给你，而非被销毁。

## 比较器输出

炖锅会发出 **红石比较器信号**，强度按锅内所有格子的填充程度换算：空锅为 0，只要有内容信号就会抬升，越满信号越强。
借此可用漏斗和比较器实现自动化。

## 小贴士

- 保持热源常燃 —— 火一灭炖锅就会暂停。
- 炖锅下方接漏斗可自动喂料；产出侧再接漏斗抽取成品，即可搭出简易自动厨房。
- 善用 `/fd recipe` 和「仅可制作」筛选，从手头材料规划料理。
- 料理回复的饥饿与饱和度远超生食，且很多附带短时增益 —— 相比生吃，下锅几乎总是值得的。
