# 沃土与堆肥

农夫乐事新增了一条肥沃土壤链，能让作物长得更快。你把杂物沤成**有机堆肥**，堆肥熟化为**沃土**，再用锄头翻成**沃土耕地**。这几种土都能长蘑菇——见 [蘑菇群落](mushrooms.md)。

整条链如下：

```
杂物  →  有机堆肥  →  沃土  →  （用锄头翻耕）  →  沃土耕地
```

## 有机堆肥

`farmersdelight:organic_compost` 是这条链的起点。它是一堆缓慢熟化为沃土的腐殖堆，上面可以种蘑菇。

**合成**（无序合成，两种配方任选）：

- `minecraft:dirt` + 2 `farmersdelight:straw` + 2 `minecraft:rotten_flesh` + 4 `minecraft:bone_meal`
- `minecraft:dirt` + 2 `farmersdelight:straw` + 2 `minecraft:bone_meal` + 4 `farmersdelight:tree_bark`

**熟化过程：** 有机堆肥会缓慢"堆沤"，经历 8 个阶段（0–7）。每次随机刻它都有一定概率推进一个阶段，越过最后阶段后便**变成 `farmersdelight:rich_soil`**。你什么都不用做，放着等即可。

想加快堆沤，可以在堆周围下功夫：

- **附近的活化方块**各自增加一点概率。活化方块包括红/棕蘑菇、蘑菇群落、灰化土、菌丝、其他堆肥堆，以及沃土 / 沃土耕地。
- **光照充足**（露天 / 明亮）比处在黑暗中效果更好。
- **紧邻水源**会带来额外加成。

因此，一堆露天、四周环绕蘑菇并挨着水的堆肥，会比孤零零躲在暗角里的堆肥沤得明显更快。

## 沃土

`farmersdelight:rich_soil` 是完全沤熟的肥沃泥土。让有机堆肥沤完（见上）即得，或破坏沃土耕地也能得到。

**作用：** 在随机刻中，沃土有一定概率**为其上方生长的植物施肥**（若上方为空，则作用于正下方的植物）——效果如同施用骨粉，并伴有常见的绿色粒子。这使它成为树木、作物、甘蔗、竹子等的极佳苗床。

有几类方块被**有意排除**，以免世界失控：草、蕨、苔藓、菌岩、大型垂滴叶、高大花朵（向日葵、紫丁香、牡丹、玫瑰丛、开花的滴水叶花）、野生作物和蘑菇群落都会被跳过，按各自正常速度生长。

沃土在种植上也等同泥土（竹子、树苗都能种在其上），并且能长蘑菇。

{% hint style="info" %}
在沃土上种一株普通的红/棕蘑菇，之后的某个随机刻，沃土会把它变成一个幼年**蘑菇群落**。见 [蘑菇群落](mushrooms.md)。
{% endhint %}

## 沃土耕地

`farmersdelight:rich_soil_farmland` 是翻耕过的沃土——本包中最优秀的耕地。

**制作方法：** **手持任意锄头右键沃土**，且其上方为空气方块，沃土即变为沃土耕地（锄头会有少许损耗）。

**作用：** 它像原版耕地一样工作，但当它完全湿润时，还会在随机刻中有一定概率**为其上的作物施肥**，因此沃土耕地上的作物比普通耕地长得更快。

**可种植的作物：** 本包的作物（番茄、卷心菜、洋葱）都接受沃土耕地作为土壤，原版作物同样可以——小麦、胡萝卜、马铃薯、甜菜根，以及西瓜/南瓜的茎都能种在其上并正常生长。

### 保持湿润

{% hint style="warning" %}
**行为仍在定稿中。** 下述补水规则描述的是沃土耕地**应有**的目标行为；该行为正在一项进行中的修复里对齐，当前版本的实际表现可能略有出入。此处记录目标行为，供你了解预期。
{% endhint %}

沃土耕地获取和保持湿度的方式与普通耕地相同：

- 当它**露天且被雨淋到**，或**数格范围内有水**（以自身为中心 9×9、同层或高一层的区域内）时，会变为**完全湿润**。
- 没有雨水或附近水源时，它会慢慢**变干**，湿度随时间流失。干燥的耕地仍能种植作物，只是没有施肥加成。
- 只有在完全湿润时，它的外观才切换为较深的湿润材质。

### 还原

若在沃土耕地正上方**放置实心方块**，它会因被压盖而**还原为普通沃土**，与原版耕地被覆盖后变回泥土完全一致。作物、西瓜、南瓜、栅栏门和移动中的活塞都**不**算作覆盖物，因此你种下的作物是安全的。

破坏沃土耕地会掉落 `farmersdelight:rich_soil`，所以翻耕绝不会白白损失。
