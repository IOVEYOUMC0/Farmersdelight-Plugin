# 绳索

绳索（`farmersdelight:rope`）是一种可攀爬的绳子，能沿墙铺设、垂入竖井、隔空敲响钟，还能用来种番茄。

**合成：** 竖着叠 2 个 `farmersdelight:straw` 得到 **4 个绳索**。（稻草来自稻米、草和小麦——见 [作物](crops.md#种子与稻草的来源)。）

## 放置与攀爬

绳索像普通方块一样放置。它呈悬垂的立柱形态，并会在视觉上与相邻物**连接**——其他绳索、墙、铁栏杆/铜栏杆、玻璃板，以及它所贴靠的任意实心方块面。

绳索**可攀爬**：站进绳中按住跳跃即可上升，视角向下则下降，与梯子或藤蔓完全一致。它还会**抵消坠落伤害**——落入绳索柱会重置你的坠落，因此也可当作安全下井的手段。

## 向下延伸绳索

你不必一格一格地往洞里放绳。**手持绳索右键一段已有绳索**，它会笔直**向下**延伸，从该绳柱底端一路铺到碰到的第一个方块为止：

- 它会填满下方每一格空气（或可替换方块）。
- 遇到第一个无法穿过的实心方块即停止，且**不会**穿过熔岩。
- 每铺一格消耗手中一个绳索。

这让你能快速把绳梯垂入峡谷或废弃矿井——顶部放一个绳索，再拿一组绳索点它即可。

## 用绳索敲钟

你可以把钟接到绳索拉绳上。在**钟的下方搭一条连续的绳柱**，然后**空手右键绳索**（且不处于潜行状态）。绳索会敲响向上找到的第一口钟。

- 钟最多可位于你点击处**上方 24 格**（服务器可调整该上限）。
- 绳柱必须不间断——任何缺口或非绳索方块都会中止搜索。

这样你在地面就能敲响村庄或基地的钟，而不必够到钟本身。

## 用绳索种番茄

绳索能让番茄**向上**生长以获得更大产量。

1. 在耕地上种出并养大一株番茄丛（`farmersdelight:tomatoes`）——见 [作物 → 番茄](crops.md#番茄)。
2. 在成熟番茄丛**正上方**放置一个**绳索**。
3. 藤蔓生长时（随时间自行生长，或被骨粉催熟时），会**顺绳攀爬**，消耗一个绳索并将其替换为一个悬挂番茄（`farmersdelight:tomato_crop_on_rope`）。
4. 只要在最顶端悬挂番茄之上继续放绳，藤蔓就会不断攀爬，在地面番茄丛之上最多叠起一列悬挂番茄（默认约 3 个高）。

每个悬挂番茄成熟后**右键收获** 1–2 个番茄，与番茄丛相同。攀爬需要光照等级 9 及以上。

{% hint style="info" %}
若移除一个悬挂番茄，它原本占据的绳索会被放回，从而保持绳柱完整，供其上方的番茄继续生长。
{% endhint %}
