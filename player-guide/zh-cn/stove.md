# 炉灶

**炉灶（Stove）** 是你的专用热源，身兼两职：

1. 在顶面烤制食物（类似营火，但更整洁、可朝向摆放）。
2. 作为 **热源** 垫在炖锅或煎锅下方。

## 合成炉灶

有序合成（工作台）：

```
[ 铁锭   ] [ 铁锭 ] [ 铁锭   ]
[ 红砖块 ] [      ] [ 红砖块 ]
[ 红砖块 ] [ 营火 ] [ 红砖块 ]
```

- `I` = `minecraft:iron_ingot`
- `B` = `minecraft:bricks`（红砖块）
- `C` = `minecraft:campfire`

产物：`farmersdelight:stove` ×1。

## 点燃与熄灭

炉灶放下时 **默认为点燃状态**。你可以手动切换火焰：

| 操作 | 使用物品 | 效果 |
|------|----------|------|
| 点燃 | **打火石** | 点燃火焰（消耗 1 点耐久） |
| 点燃 | **火焰弹** | 点燃火焰（消耗火焰弹） |
| 熄灭 | **锹**（任意） | 熄灭火焰（消耗 1 点耐久） |
| 熄灭 | **水桶** | 熄灭火焰并返还空桶 |

点燃时炉灶会发光、提供亮度，并冒出火焰与烟雾。只有 **点燃** 的炉灶才能烤食物，也只有点燃的炉灶才算作热源。

## 在顶面烤食物

1. 炉灶 **点燃** 状态下，手持带有营火烹饪配方的食物（生肉、生鱼、马铃薯等）右键其顶面。
2. 食物摆上烤面并随时间烤熟。炉灶有 **六个烤制格**，可同时烤多份。
3. 某份烤好后，成品会从炉灶顶面 **弹出**，等你拾取。

若烤制途中火熄灭，进度会缓慢回落，直到你重新点燃。若在炉灶烤面上方放了实心方块，食物会被弹出。

放到炉灶上的食物无法空手取回 —— 它会一直留在烤面上，直到烤熟后自行弹出。破坏炉灶会掉落其上仍在烤制的食物。

## 作为热源使用

把 **炖锅** 或 **煎锅** 直接放在点燃的炉灶顶上即可烹饪。这是给厨房供热最干净的方式 —— 详见炖锅与煎锅页面。

## 当心 —— 点燃的炉灶会烫伤你

站在 **点燃** 炉灶的中央烤面上会受到火焰伤害（约每次半颗心、站在上面约每秒 2 点伤害）。玩家和生物都受此影响。

- **潜行** 走上点燃的炉灶是安全的 —— 蹲下时不会被烫。
- 站在 **边缘**（外圈）是安全的，只有中央烤面会烫伤。
- 创造模式与旁观模式的玩家永远不会被烫。

穿越炉灶前先用锹或水桶熄火，或者潜行通过。

## 小贴士

- 让炉灶常燃于炖锅下方，料理就永不停摆。
- 炉灶一次可烤六份，批量烤肉烤鱼比单个营火更划算。
- 记住烫伤机制：别把点燃的炉灶铺成走道，也提醒同伴 —— 潜行才是安全的通过方式。
